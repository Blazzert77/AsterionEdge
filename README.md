# Asterion Edge

Asterion Edge est un tableau de bord tactile communautaire pour **Star Citizen**, conçu pour le **CORSAIR XENEON EDGE**.

## État du projet

**Version actuelle : v0.2.1 — phase de test**

Le projet évolue activement. L'objectif est de proposer une expérience simple : installation unique, Companion Windows discret en arrière-plan, détection automatique de Star Citizen et interface tactile adaptée au contexte de jeu.

## Fonctionnalités actuelles

- Widget iCUE pour XENEON EDGE
- Companion Windows local
- Connexion automatique Widget ↔ Companion
- Détection de Star Citizen LIVE / PTU / EPTU
- Premières pages Flight / Combat / Power / Targeting / FPS / Landing / Systems
- Lecture de `Game.log`
- Gestion initiale des keybinds
- Mode simulation
- Installateur Windows simplifié

## Prochaine version — v0.3.0

La v0.3.0 est une refonte majeure de l'expérience Asterion Edge :

- Nouvelle interface plus moderne, contextuelle et centrée sur le pilotage
- Interface française par défaut et choix de langue
- Personnalisation avancée : thèmes, couleurs, densité et actions rapides
- Détection améliorée du contexte ON FOOT / FLIGHT
- Refonte du système de keybinds et réduction des faux NOT BOUND
- Affichage des informations de session réellement disponibles : build, shard, localisation, événements
- Préparation d'un système de mise à jour via GitHub Releases
- Version affichée de manière cohérente partout : v0.3.0, v0.3.1, etc.
- Aucune fausse télémétrie : commande disponible ≠ état réel confirmé

La roadmap détaillée est disponible dans [ROADMAP.md](ROADMAP.md).

## Philosophie

Asterion Edge ne doit pas inventer de télémétrie. Si Star Citizen ne fournit pas une information de manière fiable et sûre, elle ne sera pas affichée comme un état réel.

## Disponibilité

Asterion Edge est actuellement gratuit pendant sa phase de test.
