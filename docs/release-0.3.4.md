# Asterion Edge v0.3.4 — Nouvelle interface cockpit

Intégration de l’interface fournie par l’utilisateur : app.js, style.css et index.html sont copiés à l’identique, sans retouche graphique ni changement de leur logique. Le patch fourni documente cette refonte sur la base v0.3.3.

- Panneaux ÉNERGIE, VOL, SYSTÈMES et CIBLAGE, boutons et voyants redessinés.
- Raccourcis sous les boutons et compteur des commandes à configurer.
- Statuts Companion et Star Citizen séparés.
- Onglets TARGET / MINE / SALVAGE dans l’en-tête.
- Les commandes retirées de la vue principale par cette interface restent accessibles dans les pages avancées.

Le Companion et ses commandes restent ceux de v0.3.3 ; seul le numéro de livraison est actualisé. Les voyants restent des états manuels ou estimés, sans télémétrie réelle. La détection par canal indique une présence présumée à bord.

Pour conserver strictement les fichiers reçus, le numéro interne affiché par l’interface reste v0.3.3. L’installateur, le Companion et le paquet widget sont en v0.3.4.

Quittez le Companion avant l’installation. Installateur Windows, archive portable et widget iCUE fournis.
